\section{Elevator pitch}
% ---------------------------------------------------------------------------

Most sports games assume two hands, a controller, and a body that can mash
buttons for ninety minutes. FIFA4ALL does not. We turn a MacBook webcam into
the pad for \emph{real} EA Sports FC on Amazon Luna in Google Chrome: look
left/right/up/down to hold WASD, open your mouth to hold Space (shoot), wink
to hold L (pass). Those are OS-level Quartz key holds, not a toy soccer demo
and not a virtual gamepad.

One command opens Welcome, onboarding, and practice at
\texttt{http://127.0.0.1:8765/}. A separate camera window
(\texttt{FIFA4ALL look axis}) shows the look-axis overlay; website chrome
stays in the browser. Sit straight and raise your eyebrows to recapture
center --- the same reset as overlay RESET and the site's Find your center /
Reset center. Pose lives on one shared control-state machine, so
practice calibration is the match calibration. Tongue-out used to reset too;
it was removed because it looked like a shot. Lose the face and every key
comes up. Different bodies. Same pitch.

\section{About the project}
% ---------------------------------------------------------------------------

\subsection*{What it is}

FIFA4ALL is a VTHacks accessibility hack. The long-term idea is that the
interface should adapt to the user's remaining mobility instead of forcing
the user to adapt to a controller. The weekend build is the smallest version
of that idea that still looks like \emph{FIFA}: MacBook-camera face tracking
mapped to the simplified EA Sports FC keyboard layout, injected into Amazon
Luna in Chrome.

We specifically wanted the real game. A custom soccer prototype reads as a
computer-vision demo. EA Sports FC on Luna reads as: you are actually
playing FIFA with your face.

\subsection*{How you play}

Live capture opens only the built-in \textbf{MacBook} camera (FaceTime /
built-in). It refuses iPhone and Continuity Camera indexes so a phone in the
room cannot become the tracker.

From a clone of \url{https://github.com/vthacks26/FIFA4ALL} on \texttt{main}:

\begin{verbatim}
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r tracking/requirements.txt
MPLCONFIGDIR=.cache/matplotlib python -m tracking.live --preview
\end{verbatim}

That waits until the orientation UI is listening, then opens
\textbf{http://127.0.0.1:8765/} (Welcome $\rightarrow$ onboarding $\rightarrow$
practice). The look-axis overlay is a \textbf{separate} camera window titled
\texttt{FIFA4ALL look axis} (mirrored MacBook frame, face landmarks, WASD
axis, current keys, orange RESET). You do not need \texttt{npm run dev}.

Inject without opening a browser (keeps Luna focused):

\begin{verbatim}
MPLCONFIGDIR=.cache/matplotlib python -m tracking.live --no-preview
\end{verbatim}

\texttt{--no-preview} still serves that URL and still sends keys; it does
not raise a window. \texttt{--no-preview} wins if both flags are passed.
Quit with Ctrl+C.

Open Chrome, launch Luna, start EA FC, and \textbf{click the game} so it is
focused. Quartz HID events (\texttt{CGEventPost}) land on whatever is
frontmost.

\begin{description}[style=nextline,leftmargin=1.5em]
  \item[Look / head (nose joystick)]
    WASD holds. Leave the center deadzone to move; returning to center
    releases movement.
  \item[Mouth open]
    Space hold --- shoot for as long as the mouth stays open.
  \item[Wink]
    L hold --- pass while the wink is detected (either eye; blinks
    rejected).
  \item[Raised eyebrows]
    Recentre / recalibrate pose. Overlay RESET, website calibrate
    (\texttt{POST /calibrate}), and a brow raise all call the same
    \texttt{ControlStateMachine}. A held raise fires once; opening your
    mouth to shoot does not reset. Tongue-out reset was removed because it
    was confused with shoot.
\end{description}

Keep the process running when you switch from the site to the match so
practice calibration persists into play. On the practice reticle the rest
pose is green; the looked-at direction goes gray (the pre-PR~\#7 colors,
restored after that swap).

macOS must grant \textbf{Camera} and \textbf{Accessibility} to Terminal /
Python or the camera will not open and key holds may be dropped. Exclusive
fullscreen covers the overlay; press Esc to leave it if you need the HUD or
RESET.

\subsection*{Why this mapping}

EA Sports FC on Luna can be played with a tiny keyboard set: move, shoot,
pass. That let us skip virtual gamepads and the browser Gamepad API.
MediaPipe Face Mesh measures a nose look-axis, mouth opening, an eye-wink
signal, and a brow-to-eyelid gap; the live module holds the matching keys
until the gesture ends. Combinations work (look while shooting). Face lost
means all keys released --- safer than a stuck W into the advertising
boards.

\subsection*{Who it is for}

Anyone who can sit in view of a laptop camera and move their head, mouth, or
eyes, but who cannot --- or would rather not --- use two analog sticks. It is
not a medical device. It is a working hands-free path into a game people
already recognize, built in a weekend so more people can share the same
pitch.
