# Demo flow

Intended live demo **after** Mac Accessibility + Luna key-smoke succeed. This has **not** been run against Amazon Luna in this environment.

1. Google Chrome, Amazon Luna, EA Sports FC in simplified keyboard layout.
2. Hands off the keyboard. Terminal running `python -m fifa4all --no-preview`.
3. Neutral face during the 2-second calibration, then click the Luna canvas.
4. Look / tilt left-right-up-down → player strafes/runs (WASD holds).
5. Open mouth and keep it open → charged shot (Space held).
6. Close mouth → Space up.
7. Wink and hold → pass (L held). Blink must not pass.
8. Tagline: **Different bodies. Same pitch.**

If synthetic OS keys never reach Luna, stop and show the `--key-smoke` / overlay path instead of claiming a FIFA demo.
